
# Projet d'Analyse des Ventes avec SQL et Power BI

Ce projet vise à créer un tableau de bord interactif pour l'analyse des ventes en utilisant différentes technologies. 

## Étapes du Projet

1. **Extraction des Données** : Extraction des données brutes à partir de SQL Server.
2. **Nettoyage des Données** : Nettoyage et gestion des valeurs manquantes.
3. **Transformation des Données** : Transformation et préparation des données pour l'analyse.
4. **Exportation en CSV** : Exportation des tableaux résultants au format CSV pour une utilisation ultérieure.
5. **Visualisations avec Power BI** : Importation des fichiers CSV dans Power BI pour créer des visualisations interactives et des rapports.

## Structure du Projet

- **sql scripts** : Contient les scripts SQL pour l'extraction et la transformation des données.
- **Exported data files** : Emplacement des fichiers CSV exportés.
- **Sales-Analysis.pbix** : Tableau de bord Power BI pour l'analyse des ventes.
